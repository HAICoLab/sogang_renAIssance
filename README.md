# sogang_renAIssance

서강대학교 공모전 프로젝트 저장소입니다. 프로젝트를 구성하는 코드들을 컴포넌트별 폴더로 나누어 관리합니다.

## 구성

| 폴더 | 설명 |
| --- | --- |
| [`crawler/`](./crawler) | 서강대 로욜라도서관 도서 메타데이터 크롤러 (데이터 수집) |

> 이후 전처리, 모델링, 서비스 등 컴포넌트가 추가되면 이 표에 함께 정리합니다.

## 협업 규칙

- `main` 브랜치는 항상 동작하는 상태를 유지합니다.
- 작업은 `feature/<내용>` 브랜치에서 진행하고 **Pull Request로 병합**합니다(상호 코드 리뷰).
- 커밋 메시지는 컴포넌트를 접두어로 표기합니다. 예: `[crawler] ...`, `[model] ...`
- 대용량 데이터/모델 가중치는 `.gitignore` 처리하거나 별도로 관리합니다.
